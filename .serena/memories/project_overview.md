Career-Ops 2.0 is a local job-search automation workspace centered on the nested `career-ops/` project plus a parent-root discovery pipeline. Main stack: Node.js `.mjs` scripts for core career-ops workflows, Go dashboard TUI in `career-ops/dashboard`, Python scripts in parent root for feed/jobspy/merge/orchestration. Core file-based contracts: `career-ops/data/pipeline.md` is the queue inbox, `career-ops/data/external_jobs.json` is imported discovery results, `career-ops/data/applications.md` is the tracker, `career-ops/reports/` holds evaluation reports, `career-ops/output/` holds generated CV artifacts. Parent-root `pipeline/run_pipeline.py` orchestrates feeds + JobSpy + ATS export + merge + ingest + import.
