# Career-Ops Parent Root Shim

If Claude Code is launched from the repo parent root (`CARRER OPS 2.0`), use the nested Career-Ops project instructions from:

- `career-ops/CLAUDE.md`
- `career-ops/AGENTS.md`

Project command surface is also exposed here via:

- `.claude/commands/career-ops.md`

This shim exists only so parent-root launches can still discover the Career-Ops command surface.
